# 우쭈쭈 바이러스 — 몸속 정복 대작전

작은 바이러스 하나로 사람의 몸 전체를 감염시키는 모바일 웹 게임입니다. 바이러스가 공격하고 면역 탑이 막는, 거꾸로 된 타워 디펜스예요.

## 실행

빌드 과정 없이 `index.html` 하나로 돌아갑니다. 그림·소리는 `assets/` 폴더에서 불러오기 때문에, 파일을 직접 열기보다 간단한 웹 서버로 여는 게 좋아요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages로 공개하려면 저장소 설정 → Pages에서 `main` 브랜치 루트를 선택하면 됩니다.

## 게임 흐름

1. **잠입**: 조이스틱으로 움직이며 길 벽을 감염시켜요. 보초 시야(노란 부채꼴)에 걸리면 들켜요.
2. **둥지**: 카드를 눌러 바이러스를 둥지에 모으면 저절로 불어나요.
3. **돌격**: 면역 공백(화면 테두리가 초록색)에 돌격하고, 변이 카드 3장 중 하나를 골라요.
4. **연구소**: 받은 DNA로 카드를 강화하고, 몸통·껍질·가시 카드 3장을 조합해 내 바이러스를 만들어요.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 게임 전체 코드(HTML·CSS·JS 한 파일) |
| `assets/*.png, *.jpg` | 캐릭터·탑·지도·인트로 그림 |
| `assets/snd/*.mp3` | 배경음악 4곡, 짧은 효과 음악 4개 (효과음은 코드로 합성) |

진행 상황은 브라우저 저장소(localStorage)에 저장됩니다.
